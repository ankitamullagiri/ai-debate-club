# Project: AI Debate Club

Two AI agents (PRO and CON) debate a topic for 3 rounds; a judge agent scores them.
Stack: Python, openai SDK via OpenRouter, Gradio, pytest. Code lives in `arcade/`.

## How to work with me (I'm learning)
- I'm building this to learn. Explain the idea first, then show code in small pieces.
- Prefer that I type the code. Only edit files directly if I ask you to.
- After each piece, explain what each part does and what could go wrong.
- When I hit an error, help me read the error message before giving the fix.
- Ask me questions to check I understand, like an interview would.

## Git
- I run git commands myself. Tell me what to commit and suggest a short message.
- Never add Co-Authored-By or any AI attribution to commits.

## Rules
- Never print, log or commit the contents of `.env`.
